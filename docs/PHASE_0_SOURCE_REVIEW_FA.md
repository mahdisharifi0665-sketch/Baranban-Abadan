# بررسی اولیه منابع داده — فاز صفر باران‌یار

تاریخ بررسی: 2026-11-11
وضعیت: بررسی رومیزی اولیه؛ هنوز آزمون اتصال زنده از محیط اجرای اپ یا سرور انجام نشده است.
هدف: شناسایی گزینه‌های اولیه برای پیش‌بینی بارش ۰–۶ ساعت، ۶–۲۴ ساعت و ۷ روز در محدوده آبدان.

## جمع‌بندی اجرایی
- گزینه پیشنهادی برای نمونه فنی اولیه: Open-Meteo Forecast + Ensemble API، مشروط به تأیید مجوز کاربرد نهایی و آزمون دسترسی.
- گزینه‌های مستقل برای مقایسه و پشتیبان: ECMWF Open Data و NOAA GFS/GEFS؛ داده DWD ICON نیز برای بررسی تکمیلی.
- هیچ منبعی هنوز برای محصول نهایی انتخاب نشده است.
- رزولوشن بسیاری از محصولات جهانی در مقیاس حدود چندین تا ده‌ها کیلومتر است؛ بنابراین شعاع هدف ۵ کیلومتر به‌خودی‌خود به معنی داده مستقل یا دقت مکانی ۵ کیلومتری نیست.
- احتمال درصدی فقط پس از دریافت اعضای ensemble معتبر و کنترل کامل داده محاسبه خواهد شد.

## 1. Open-Meteo — نامزد نمونه فنی
مستندات رسمی:
- Forecast API: https://open-meteo.com/en/docs
- Ensemble API: https://open-meteo.com/en/docs/ensemble-api
- شرایط و کد پروژه: https://github.com/open-meteo/open-meteo

نکات مستندشده:
- Ensemble API اعضای جداگانه مدل‌هایی از جمله DWD ICON EPS، GFS Ensemble و ECMWF IFS Ensemble را فهرست می‌کند.
- متغیر بارش ساعتی (precipitation) در API ensemble وجود دارد.
- پاسخ ساعتی برای هر عضو ensemble ارائه می‌شود؛ این ساختار می‌تواند مبنای محاسبه احتمال عبور از آستانه‌ها باشد، مشروط به اعتبارسنجی مخرج و کیفیت اعضا.
- API از چند مختصات در یک درخواست پشتیبانی می‌کند؛ با این حال این قابلیت به معنی تفکیک مکانی مستقل در شعاع ۵ کیلومتر نیست.
- مستندات فعلی افق پیش‌فرض ۷ روز و امکان افق‌های بیشتر را توصیف می‌کنند؛ افق واقعی هر مدل/عضو باید جداگانه کنترل شود.
- شرایط عمومی اعلام‌شده، استفاده رایگان را برای توسعه‌دهندگان متن‌باز و کاربرد غیرتجاری بیان می‌کند؛ برای استفاده تجاری باید با ارائه‌دهنده درباره مجوز/پلن مناسب توافق شود.
- داده‌ها با مجوز CC BY 4.0 معرفی شده‌اند و انتساب منبع لازم است.

ارزیابی:
- مزیت: راه‌اندازی نمونه فنی سریع‌تر، خروجی JSON و دسترسی یکپارچه به چند ensemble.
- ریسک: شرایط استفاده تجاری، محدودیت درخواست، وابستگی به سرویس واسط، و نیاز به بررسی دقیق مدل/عضو/چرخه و زمان‌بندی در منطقه آبدان.
- تصمیم: مناسب برای نمونه فنی و ارزیابی اولیه؛ انتخاب نهایی منوط به تأیید مجوز و آزمون است.

## 2. ECMWF Open Data
منابع رسمی:
- https://www.ecmwf.int/en/forecasts/datasets/open-data
- https://data.ecmwf.int/

نکات مستندشده:
- بخشی از داده‌های پیش‌بینی بلادرنگ IFS و AIFS به‌صورت رایگان منتشر می‌شود.
- صفحه رسمی، مجوز CC BY 4.0 و امکان استفاده/بازنشر با انتساب مناسب را توضیح می‌دهد؛ شرایط استفاده ECMWF نیز باید رعایت شود.
- داده‌ها عمدتاً در قالب GRIB2 هستند و به پردازش تخصصی نیاز دارند.
- در اطلاعیه رسمی ۲۰ اکتبر ۲۰۲۶، انتشار IFS با شبکه ۰٫۱ درجه در کنار ۰٫۲۵ درجه اعلام شده است؛ داده ۰٫۱ درجه حدود دو ساعت دیرتر منتشر می‌شود.
- آرشیو Open Data به‌صورت چرخشی و محدود به حدود ۱۲ چرخه اخیر (تقریباً ۲ تا ۳ روز) توصیف شده است.

ارزیابی:
- مزیت: منبع اولیه معتبر و مستقل، امکان کنترل مستقیم محصول و منشأ داده.
- ریسک: دریافت و پردازش GRIB2، حجم داده، تأخیر انتشار و نیاز به پیاده‌سازی زیرساخت.
- تصمیم: گزینه مناسب برای مرحله مقایسه مستقل و پشتیبان؛ برای نمونه اول احتمالاً پیچیده‌تر از Open-Meteo است.

## 3. NOAA GFS و GEFS
منابع رسمی:
- https://nomads.ncep.noaa.gov/
- https://nomads.ncep.noaa.gov/cgi-bin/filter_gfs_0p25.pl
- https://nomads.ncep.noaa.gov/cgi-bin/filter_gens.pl
- https://nomads.ncep.noaa.gov/info.php?page=opendap_grib_migration

نکات مستندشده:
- NOMADS امکان دریافت زیرمجموعه GRIB2 بر اساس محدوده جغرافیایی، زمان، سطح و متغیر را فراهم می‌کند.
- مستندات GFS ۰٫۲۵ درجه متغیرهایی از جمله بارش تجمعی (APCP)، نرخ بارش (PRATE)، CAPE و PWAT را نشان می‌دهند.
- صفحه GEFS دسترسی به داده ensemble را نشان می‌دهد؛ رزولوشن و افق هر محصول باید از چرخه جاری و مستندات همان محصول استخراج شود.
- NOAA در راهنمای رسمی، مهاجرت از OpenDAP به GRIB Filter را توضیح داده است.

ارزیابی:
- مزیت: دسترسی مستقیم به محصولات خام و مسیر ensemble مستقل.
- ریسک: پیچیدگی پردازش GRIB2، تغییر ساختار فایل/چرخه و نیاز به مدیریت دانلود و گزینش متغیر.
- تصمیم: نامزد مناسب برای منبع مستقل مقایسه‌ای، نه الزاماً منبع اول نسخه اولیه.

## 4. DWD ICON
منابع رسمی:
- https://opendata.dwd.de/
- https://www.dwd.de/EN/ourservices/nwp_icon_tutorial/pdf_volume/icon_tutorial2025_en.pdf
- https://www.dwd.de/DE/leistungen/nwv_icon_tutorial/pdf_einzelbaende/icon_tutorial2024.pdf

نکات مستندشده:
- DWD مدل جهانی و منطقه‌ای ICON و محصولات منطقه‌ای مانند ICON-EU و ICON-D2 را مستند کرده است.
- داده‌های عمومی بخشی از محصولات در Open Data Server منتشر می‌شوند.
- ساختار شبکه ICON می‌تواند نامنظم/مثلثی باشد و برای برش/درون‌یابی به ابزارهای تخصصی نیاز دارد.
- مدل‌های محلی D2 برای اروپا طراحی شده‌اند؛ پوشش آن‌ها برای آبدان قابل فرض نیست. محصول جهانی یا ICON EPS باید جداگانه بررسی شود.

ارزیابی:
- مزیت: منبع مستقل دیگر و گزینه ensemble.
- ریسک: پیچیدگی شبکه/پردازش و نامناسب بودن برخی محصولات منطقه‌ای برای ایران.
- تصمیم: بررسی تکمیلی فقط برای محصول جهانی و ensemble دارای پوشش آبدان.

## 5. محدودیت مکانی شعاع ۵ کیلومتر
- مختصات هدف فعلاً کاری و نیازمند تأیید نهایی مالک است.
- شبکه ۰٫۱ درجه در عرض جغرافیایی آبدان در مقیاس حدود ۱۱ کیلومتر شمالی-جنوبی است؛ بنابراین شعاع ۵ کیلومتر از اندازه یک سلول شبکه‌ای کوچک‌تر است.
- مختصات متعدد ممکن است به یک سلول یا مقادیر بسیار نزدیک نگاشت شوند؛ تعداد نقاط درخواست‌شده را نباید با تعداد مشاهدات مستقل اشتباه گرفت.
- در نسخه اولیه، خروجی باید به‌عنوان پیش‌بینی شبکه‌ای برای نزدیک‌ترین سلول/سلول‌های منبع معرفی شود، نه رادار یا نقشه بارش با تفکیک ۵ کیلومتر.
- هر روش downscaling یا درون‌یابی باید جداگانه تعریف، مستند و اعتبارسنجی شود؛ در غیر این صورت مقدار خام شبکه حفظ شود.

## 6. آزمون‌های لازم پیش از انتخاب منبع
1. بررسی مجوز و هزینه برای سناریوی انتشار واقعی باران‌یار.
2. آزمون دسترسی شبکه‌ای از زیرساختی که برنامه/بک‌اند واقعاً در آن اجرا خواهد شد؛ جست‌وجوی وب، دسترسی API را اثبات نمی‌کند.
3. دریافت چند چرخه متوالی و بررسی زمان انتشار، تازگی، پایداری و محدودیت نرخ.
4. کنترل وجود precipitation ساعتی، واحد mm، تعریف بازه زمانی و نحوه انباشت.
5. کنترل اعضای ensemble، تعداد مورد انتظار، اعضای مفقود، نام‌گذاری و زمان اعتبار.
6. مقایسه نقطه آبدان با چند نقطه پیرامونی برای فهم رفتار سلول شبکه و انتخاب سلول.
7. کنترل تفاوت forecast hourly، daily sum و rolling 24-hour accumulation.
8. ثبت پاسخ خام، زمان دریافت، نسخه محصول، منبع، خطا و نتیجه QC.
9. تطبیق نمونه‌ها با مشاهدات باران‌سنجی معتبر در آبدان یا نزدیک‌ترین ایستگاه قابل اتکا.
10. تهیه گزارش تصمیم شامل مزایا، معایب، هزینه، مجوز، پوشش و ریسک.

## تصمیم پیشنهادی فاز صفر
ابتدا یک نمونه فنی محدود با Open-Meteo Forecast و Ensemble API ساخته و از نظر دسترسی، کامل بودن اعضا، بارش ساعتی، زمان‌بندی و مجوز بررسی شود. هم‌زمان یک مسیر مستقل از ECMWF Open Data یا NOAA GEFS برای cross-check انتخاب شود. تا پایان آزمون‌ها، منبع نهایی، دقت محلی، پوشش ۵ کیلومتر و احتمال کالیبره‌شده تأییدشده تلقی نمی‌شوند.

## وضعیت اجرایی
این سند فقط بررسی مستندات عمومی است. هیچ API زنده‌ای از محیط اپ یا سرور فراخوانی نشده، هیچ کلید یا اشتراکی ثبت نشده، داده هواشناسی دریافت و اعتبارسنجی نشده و هیچ منبعی برای انتشار نهایی تأیید نشده است.
