# باران‌یار

برنامه اندرویدی فارسی و ساده برای پیش‌بینی بارش در آبدان و محدوده موردنظر کاربر.

## سند مرجع پروژه
**نسخه طراحی فعال: باران‌یار ۶**

تمام تصمیم‌های محصول، محدوده، طراحی رابط، منابع داده، محدودیت‌ها و نقشه راه فقط در این سند نگهداری می‌شوند:

[مشاهده سند مرجع باران‌یار ۶](docs/BARANYAR_V6_MASTER_FA.md)

## وضعیت
- نسخه ۵.۱: هسته فنی و آزمون‌های معتبر آن در شاخه اصلی حفظ شده است.
- نسخه ۶: مبنای طراحی و ادامه توسعه است؛ هنوز APK منتشر نشده است.
- شاخه اصلی توسعه: main
- استفاده: شخصی و غیرتجاری
- نقطه مرجع دقیق: تا تأیید نهایی مختصات، قطعی نیست.

## ساختار
- docs: سند مرجع و سوابق فنی لازم
- src: هسته پردازش و اتصال داده
- schemas: قرارداد داده
- qa: آزمون‌ها
- data: داده مرجع ضروری
- .github/workflows: اجرای خودکار آزمون‌ها

اصل پروژه: رابط کاربری خلوت؛ هیچ عدد یا احتمال بارشی بدون داده معتبر نمایش داده نمی‌شود.
