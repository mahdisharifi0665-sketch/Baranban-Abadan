# هسته فنی باران‌یار ۶

موتور و زیرساخت فنی پیش‌بینی بارش برای نقطه مرجع آبدان، شهرستان دیر، استان بوشهر. توسعه اپ اندروید تا زمان تثبیت و اعتبارسنجی هسته متوقف است.

## مرجع واحد پروژه
**نسخه فعال و تنها نسخه محصول: باران‌یار ۶**

تمام تصمیم‌های محصول، مختصات، محدوده، طراحی رابط، منابع داده، محدودیت‌ها و نقشه راه در یک سند نگهداری می‌شوند:

[سند مرجع واحد باران‌یار ۶](docs/BARANYAR_V6_MASTER_FA.md)

## وضعیت واقعی
- شاخه مرجع توسعه: `main`
- نقطه مرجع تثبیت‌شده: `28.0801523° N, 51.77113355° E`
- هسته پردازش بارش، آرشیو پیش‌بینی، adapterهای مشاهده‌ای و زمانی، schemaها و تست‌های فنی در همین نسخه یکپارچه‌اند.
- مستندات تخصصی باقی‌مانده، اسناد پشتیبان همین نسخه‌اند؛ نسخه محصول جداگانه نیستند.
- توسعه اپ اندروید و APK فعلاً خارج از دامنه کار است؛ تمرکز فعلی فقط بر هسته فنی و اعتبارسنجی پیش‌بینی است.
- منبع نهایی پیش‌بینی و مشاهده محلی آبدان هنوز تأیید عملیاتی نشده‌اند.

## ساختار
- `docs/BARANYAR_V6_MASTER_FA.md`: تنها مرجع محصول و تصمیم‌ها
- `src/`: هسته پردازش و adapterها
- `schemas/`: قراردادهای داده
- `qa/`: آزمون‌ها و ابزارهای بررسی
- `data/`: داده مرجع ضروری
- `.github/workflows/`: کنترل خودکار کیفیت
- `package.json`: دستورهای آزمون و ابزار توسعه

اصل پروژه: رابط کاربری ساده؛ هیچ مقدار یا احتمال بارشی بدون داده معتبر نمایش داده نمی‌شود. توسعه فقط روی `main` انجام می‌شود.
